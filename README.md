# YesnielDev Portfolio

Minimalist and professional portfolio built with **Astro**.

## 🚀 Getting Started

### Prerequisites

You need to have [Bun](https://bun.sh) installed.

### Installation

```bash
bun install
```

### Development

```bash
bun dev
```

## 🛠️ Tech Stack

- **Astro** - Web Framework
- **TypeScript** - Logic
- **Vanilla CSS** - Styling
